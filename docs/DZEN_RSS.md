# Инструкция: RSS для Дзена (карточки павших)

> Источник требований: issue `mem-2026/eo#16` «RSS нормативы Дзена (кратко из извлечённого)» + официальная справка Дзена (раздел «Описание материала», «Описание медиа», «Пример размеченной ленты»).
> Назначение: карточки павших из CSV планируется отправлять в Дзен по каналу RSS.

---

## 1. Обязательные элементы `item`

| Элемент | Требование Дзена | Примечание для наших карточек |
|---|---|---|
| `title` | Заголовок. Обязателен, но **игнорируется при конвертации в пост** — если хотите заголовок в посте, продублируйте его внутри `content:encoded` | У нас = ФИО (title и H1 уже совпадают) |
| `category` | Способ публикации / тип / индексация / комментарии — см. §3 | ⚠️ Не заполняется — см. §3.1 |
| `guid` | Уникальный идентификатор статьи. Для редактирования/повторной отправки указывайте изначальный `guid` **или URL**, чтобы не создавать дубликаты | Берём `link` (содержит `document_id`) |
| `pubDate` | Дата и время публикации в RFC822: `Wed, 02 Oct 2002 15:00:00 +0300`. Можно планировать: минимум — 1 час. **Для черновиков (`native-draft`) не работает** | Библиотека `feed` форматирует сама; нужен `published` — см. §5 |
| `link` | URL статьи (ЧПУ, без UTM) | `bitva-za-krym-1942-<document_id>` |
| `pdalink` | Ссылка на версию, адаптированную для мобильных устройств (необязательно) | Пока не используется |
| `description` | Описание для карточки в ленте | ⚠️ Не гарантировано — см. §5 |
| `enclosure` | Обложка, минимум **700px** ширина, JPEG/GIF/PNG. Может быть единственным медиа или дублировать `figure`/`img`. **Если картинок в `figure`/`img` нет, но есть в `enclosure` — в посте они опубликуются как обычные изображения (до 10)** | ❌ В карточках нет изображений — см. §5 |
| `content:encoded` | Полный текст, **рекомендуемый объём — не менее 300 знаков** с пробелами, HTML-разметка | ⚠️ Короткие карточки не дотягивают — см. §5 |
| `author` | Автор материала. **Только для партнёров сервиса «Новости в Дзене»** (программа бесшовного потребления новостей). Правила: кириллица, имя+фамилия (+отчество), без должности, одинаковое написание всегда, несколько авторов через запятую | Пока не используется |

## 2. HTML-теги внутри `content:encoded`

Разрешены:

- `p`, `a`, `b`, `i`, `u`, `s` — абзацы, ссылки, жирный, курсив, подчёркивание, зачёркивание
- `h1`, `h2`, `h3`, `h4` — заголовки (`h1`, `h2` — первого уровня; `h3`, `h4` — второго уровня)
- `blockquote` — цитаты
- `ul/ol` + `li` — списки (**внутри списка не поддерживается другое форматирование**)
- `figure`, `img` — изображения
- `video` — только MP4, минимум 800×400

### 2.1. Оглавление (якоря)

Можно добавить оглавление: заголовку `h2`, `h3` или `h4` присваивается `id`, затем ссылка на якорь:

```html
<h2 id="neravnoznachne_po_smsly">Неравнозначные по смыслу</h2>
<a href="#neravnoznachne_po_smsly">Неравнозначные по смыслу</a>
```

### 2.2. Коды вставки (виджеты)

`content:encoded` поддерживает коды вставки разных платформ. RSS-лента **автоматически превращает в виджет** ссылки:

- Видео Дзена
- VK Видео
- YouTube

### 2.3. ВАЖНО про формат поста

> В формате **постов** поддерживается форматирование **только гиперссылок и списков**. Остальное форматирование в постах не поддерживается.

## 3. `category` — способ публикации

### 3.1. Способ публикации (если не указать — материал публикуется сразу)

- `native-draft` — материал сохранится на платформе как **черновик**. Можно отредактировать и опубликовать позже. **Для черновиков не действует время публикации из `pubDate`.**

### 3.2. Тип публикации

- `format-article` — статья
- `format-post` — пост

**Авто-конвертация, если формат не указан:**

| Условие | Результат |
|---|---|
| Меньше **800 символов** и **нет картинок** | Конвертация в пост |
| Меньше **600 символов** и **до 10 картинок** | Конвертация в пост |
| Содержит код вставки или эмбед | Конвертация в статью |
| Все остальные случаи | Автоматическая публикация как статья |

**Если выбран `format-post`, но в нём больше 4000 символов и больше 10 картинок** — публикация преобразуется в статью.

> Договорённость: карточки павших пока без изображений → по правилам авто-конвертации попадут в **`format-post`**, даже если `category` не заполнен.

### 3.3. Индексация

- `index` — материал индексируется в поисковых системах
- `noindex` — материал не индексируется

### 3.4. Комментирование

- `comment-all` — комментировать могут все
- `comment-subscribers` — только подписчики
- `comment-none` — комментарии закрыты

### 3.5. Теги (категории) на основе данных карточки

При генерации карточки предусмотреть формирование тегов из полей CSV:

- **Воинская часть / соединение** (`warunit`) — тег по наименованию войсковой части или соединения.
  - Пока пишем значение как есть; после подключения словаря авто-замены тег будет строиться от нормализованного наименования.
- **Захоронение** (`primary_burial` / `current_burial`) — тег по месту захоронения.
  - Приоритет: `primary_burial`; при наличии уточнённого `current_burial` — можно использовать оба или выбрать основной.

## 4. Ограничения Дзена

- Минимум **10 материалов** при первой разметке
- Не более **500 публикаций** за раз
- Обновления работают **7 дней** после первой загрузки
- Изображения — минимум **700px** ширина
- Отложенная публикация через `pubDate` — минимум **1 час**
- `format-post` > 4000 символов и > 10 картинок → преобразование в статью

## 5. Что не хватает нашим карточкам (v1 и v2) для Дзена

Скрипты `new-csv-to-markdown.mjs` (v1) и `new-csv-to-markdown-v2.mjs` (v2) генерируют корректные страницы для сайта, но для RSS-канала Дзена есть пробелы:

1. **Обложка `enclosure` отсутствует.** Нет ни одного изображения.
   - Возможное решение: генератор OG-карточек уже есть в шаблоне (`astro-og-canvas`, `src/pages/og/[...image].ts`). Можно генерировать OG-изображение (ФИО + префикс) и класть его в `enclosure`. Также можно класть картинку и в `figure`/`img` внутри текста — тогда она появится и в ленте как изображение поста.
2. **Длина `content:encoded` < 300 знаков.** Короткие карточки Дзен отбрасывает (рекомендуемый объём — не менее 300 знаков).
   - **Решение (согласовано):** авто-замена «войсковая часть → наименование + историческая справка (1–3 абзаца)». Это одновременно наращивает текст до минимума и повышает ценность материала.
   - Скрипт пока пишет `warunit` как есть (TODO: словарь подмен `data/dictionaries/units_dict.json` или аналог).
3. **`description` не гарантирован.** Поле не задано во frontmatter; формируется из тела (`getPostDescription`), при коротком теле может быть пустым.
   - Решение: проверять длину/наполнение `description` при доработке `feed.ts`.
4. **`feed.ts` не добавляет `enclosure`.** Нужно доработать `src/utils/feed.ts`: добавить `enclosure`, проверить `description` и длину `content:encoded`.
5. **`published` обязателен.** Схема Retypeset требует поле `published` (z.date()). В карточках оно сейчас не выводится — для RSS `pubDate` будет невалиден.
   - Решение: добавить `published` во frontmatter карточки (например, из колонки «Дата» CSV).
6. **Формат поста ограничен.** Если карточки попадут в `format-post`, поддерживаются только ссылки и списки. Значит, жирное выделение полей (`**Погиб**` и т.д.) в посте Дзена отобразится без форматирования — это нужно учесть при доработке конвертера.

## 6. Официальный образец RSS от Дзена

```xml
<?xml version="1.0" encoding="UTF-8"?> <rss
version="2.0" xmlns:content="http://purl.org/rss/1.0/modules/content/"
xmlns:dc="http://purl.org/dc/elements/1.1/" xmlns:media="http://search.yahoo.com/mrss/"
xmlns:atom="http://www.w3.org/2005/Atom" xmlns:georss="http://www.georss.org/georss">
<channel> <title>Пастернак</title>
<link>http://example.com/</link> <language>ru</language>
<item> <title>Андроид восстановит ферму в Японии</title>
<link>http://example.com/2023/07/04/android-happy-farmer</link>
<pdalink>http://m.example.com/2023/07/04/android-happy-farmer</pdalink>
<guid>2fd4e1c67a2d28fced849ee1bb76e7391b93eb12</guid> <pubDate>Tue, 04
Jul 2023 04:20:00 +0300</pubDate> <media:rating
scheme="urn:simple">nonadult</media:rating>
<category>native-draft</category> <enclosure
url="http://example.com/2023/07/04/big_pic1.jpg" type="image/jpeg"/>
<content:encoded> <![CDATA[<p>Здесь находится полный текст статьи. Его
могут прерывать картинки.</p> <figure> <img
src="http://example.com/2023/07/04/big_pic1.jpg"> <figcaption> Первый
андроид-фермер смотрит на свои угодья <span class="copyright">Михаил
Родченков</span> </figcaption> </figure> <p>Продолжение статьи
после вставленной картинки. В статье рассказывается о <a
href="https://ru.wikipedia.org/wiki/Вспашка">технологии вспахивания земли</a>,
которую использует японский андроид-фермер.</p> <p>Что фермеры используют для
работы: <ul> <li><i>тяпки</i>;</li>
<li><b>грабли</b>;</li>
<li><u>велосипеды</u>;</li>
<li><s>плуги</s>;</li> </p> <p>Статья продолжается.
Андроид копает картошку. Фермы развиваются. Япония продолжает удивлять.</p>]]>
</content:encoded> </item> </channel> </rss>
```
